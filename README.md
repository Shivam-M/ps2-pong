# PS2 Pong
 
_Pong clone for the Sony PlayStation 2 - created using [PS2SDK](https://github.com/ps2dev/ps2sdk/) and [gsKit](https://github.com/ps2dev/gsKit)_

Features
--------
* Local 1v1 multiplayer
* Various game modes
  * First to reach score
  * Time limit
  * Free play
* Audio support
* Adjustable screen X/Y offsets
